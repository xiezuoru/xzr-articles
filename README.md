# 谢作如历年发表的文章

## 说明

从2003年发表第一篇文章开始，经不完全统计，居然也写了数百篇长短不齐的文章。借助知网，我将自己的文章逐步整理出来。

我写的文章，大致可以分为如下几类：

1.教育信息化、AI赋能教育。

2.信息技术（信息科技）教育。

3.跨学科学习。

创客教育、STEM（STEAM）教育、综合实践活动。

4.人工智能教育。

5.其他方面。

如育儿、教育评价之类。

## 组织形式

大部分按照时间来整理，部分专题、专栏则独立呈现。比如，从2015年开始，我于中国信息技术教育杂志上开专栏“生活技术探究”，每年要完成11篇，算起来已经坚持了4年。为此，专门用一个文件夹来存放。
